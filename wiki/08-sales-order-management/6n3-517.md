## 目的

得意先階層管理アプリは、得意先階層の登録、コピー、編集、および削除と、複数レベルの階層ノードの割当に役立ちます。階層の有効時間枠を管理することもできます。階層は、この指定された時間枠内のプロセスに対してのみ考慮されます。

得意先階層 - 分析: 販売分析でこの階層タイプを使用して、トランザクションデータを予測し、洞察に富んだ情報を取得します。

得意先階層 - 販売: この階層タイプは、販売伝票および請求伝票での価格決定に使用されます。この階層には、同じ販売エリアに属する顧客情報が含まれます。テキストノードを追加することができます。テキストノードは、州や地域などのあらゆる種類の情報を示すことができ、階層のより適切な編成に役立ちます。さらに、これらのテキストノードは価格設定関連として更新することができます。階層には、得意先の販売エリアが関連付けられている必要があるビジネスパートナノードも含まれます。

### ロール

SAP から提供される以下のビジネスロールテンプレートを使用して、ビジネスロールを登録し、それらを個別のテストユーザに割り当てます。

または、利用可能な場合は、SAP から提供される以下のスペースを使用することができます。スペーステンプレートを使用して、必要な事前定義済アプリを含むページのあるスペースを登録し、それをビジネスロールに割り当てます。その後、このビジネスロールを個別のユーザに割り当てます。

詳細については、SAP S/4HANA Cloud Public Editionの[Product Assistance](https://help.sap.com/docs/SAP_S4HANA_CLOUD/53e36b5493804bcdb3f6f14de8b487dd/ec310a8b669a45ca898dc4dd91d97de2.html)でテンプレートからのビジネスロールの作成方法を参照してください。

| --- | --- | --- | --- | --- |
| マスタデータスペシャリスト - ビジネスパートナデータ | SAP_BR_BUPA_MASTER_SPECIALIST | マスタデータ - ビジネスパートナ/ビジネスパートナガバナンス/ビジネスパートナガバナンス/ビジネスパートナガバナンス | SAP_BR_BUPA_MASTER_SPECIALIST / SAP_CA_SPT_MDG_BP_GOV_PC / SAP_CMD_SPT_BP_GOV_PC / SAP_CA_SPT_MDG_BP_WFUSR_PC |  |

|  |
| --- |
| 注記 ZATCA の電子請求書に関する規制に準拠するには、電子伝票を生成する前に、すべての必須項目 (地名 2、地名 3、地区など) がビジネスパートナフォームに正しく入力されていることを確認します。これは、電子請求書を税務当局ポータルに送信する前の検証が正常終了するために必要です。この情報は、電子伝票のタイプに応じて、ZATCA によって要求適切な XML タグを入力するために使用されます。ZATCA のガイドラインの詳細については、Electronic Invoice XML Implementation Standard Guidelines を参照してください。 |

目的

以下の手順では、得意先階層管理 (F5794)アプリを使用した販売および分析タイプの得意先階層に関する指示を示します。

前提条件

この章を開始する前に、前の章[得意先マスタデータ - 一般データの登録](#unique_8) [ ページ] 6を完了しておく必要があります。

一般データエントリを保存したら、前の章で説明されている手順に従ってください。
