## 目的

注意！这是未审核准确性的机器翻译文档。要发送有关翻译的反馈，您可以在 SAP Signavio Process Navigator 中针对您的国家/地区版本在范围项目页面上创建客户工单。

在本文档中，您将找到有关如何创建功能位置和设备的描述 SAP S/4HANA 系统的主数据记录。描述包括这些数据 与主数据相关的段，以便在“常规”系统环境中工作。 阅读器主要了解哪些数据段和字段通常需要填充。 输入值。与 S/4 HANA 内容范围无关的字段 但未在本文档中描述 SAP Best Practices 交付，尽管它们可能 显示在 UI 上。

按此处描述创建的功能位置和设备主记录可用于服务订单、服务确认和服务合同。

| 3 | 创建功能位置 | 在 创建技术对象 屏幕上，选择 技术对象类型 ： 功能位置 。在下一屏幕中，维护以下条目：技术对象类型： 功能位置结构标识 ： YBPM （最佳实践的结构标识）技术对象 ：<输入标识符，例如> ZZ01技术对象类别 ： S （客户位置）选择 继续 。 |  |  |
| 4 | 维护常规数据 | 在 创建技术对象：ZZ01 屏幕的 常规数据 部分中，维护以下条目：描述 ：<例如， 建筑物 A >（可选）维护其他常规数据，然后导航到 位置数据 部分。 |  |  |
| 5 | 维护位置数据 | 在 中 位置数据 部分中，维护以下条目：维护工厂 ：<维护相关工厂，例如， 1710 对于 US>备注 属于同一结构的技术对象必须都具有相同的工厂。 已分配。或者，您可以保留工厂信息 所有技术对象均为空。（可选）维护更多详细信息，例如地址信息。 |  |  |

### 创建设备主数据

目的

在此测试步骤中，维护安装在功能位置中的设备的记录。

过程

| 测试步骤编号 | 测试步骤名称 | 指令 | 预期结果 | 备注 |
| --- | --- | --- | --- | --- |

| 2 | 打开应用 | 打开 创建技术对象 。 |  |  |
| 3 | 创建设备 | 在 创建技术对象 屏幕上，选择 技术对象类型 ： 设备 。在下一屏幕中，维护以下条目：远程保存智能对象类型： 设备技术对象 ：<空>有效期自： <当天日期>技术对象类别 ： S （客户设备）选择 继续 。 |  |  |
| 4 | 维护常规数据 | 在 创建技术对象：<设备标识> 屏幕的 常规数据 部分中，维护以下条目：描述 ：<例如， 打印机 A1 >（可选） 客户质保 ： 担保开始/结束（可选） 供应商质保 ： 担保开始/结束备注 内部维修流程（范围项目 3XK）支持和 集成了基于日期的质保（质保 period）。在内部维修中，您可以使用质保类型 客户保修和供应商保修。您需要输入质保开始日期和质保结束日期。 设备主数据中的日期。如果您已输入 客户和/或供应商保修的结束日期 设备，系统检查保修结束日期是否为 在内部维修的创建日期之前。图标指示内部数据的创建日期。 维修在保修期内。（可选）维护其他常规数据，例如制造商信息、模型编号等，然后导航到 位置数据 部分。 |  |  |
| 5 | 分配物料和序列号 | 选择 附加功能 > 显示序列号数据 。输入以下内容并选择 。 输入 ：材料 ： TG20 |  |  |
| 6 | 维护位置数据 | 在 中 位置数据 部分中，维护以下条目：维护工厂 ：<维护相关工厂，例如， 1710 对于 US>备注 属于同一结构的技术对象必须都具有相同的工厂。 已分配。或者，您可以保留工厂信息 所有技术对象均为空。（可选）维护更多详细信息，例如地址或房间信息。 |  |  |
| 7 | 保存设备 | 或者，您可以维护附加信息，例如合作伙伴 信息等 组织 数据 部分。选择保存。 |  |  |
| 8 | 在功能位置安装设备 | 在 更改技术对象：<设备标识> 屏幕，导航至 结构 部分。选择 更改结构：安装 。在 更改安装位置 对话框中，维护以下条目：上级技术对象 ： ZZ01-001位置 ：<留空>安装日期/时间 ：<保留系统建议>选择 确定 。选择 保存 。 |  |  |
