## 目的

この文書では、S/4 HANA システムで機能場所および設備マスタデータレコードを登録する方法について説明します。この説明には、"標準的" なシステム環境で処理するマスタデータに関連するデータセグメントが含まれています。読者は、通常、入力値を入力する必要があるデータセグメントおよび項目について主に学習します。SAP Best Practices による S/4 HANA コンテンツ配信の範囲に関連しない項目については、UI に表示される場合もありますが、この文書では説明されていません。

ここでの説明に従って登録した機能場所および設備マスタレコードは、サービスオーダ、サービス確認、およびサービス契約で使用することができます。

## 前提条件

### システムアクセス

| システム | 詳細 |
| --- | --- |
| システム | SAP Fiori ラウンチパッドからアクセスすることができます。各自のロールに割り当てられている各種アプリにアクセスするための URL がシステム管理者から提供されます。 |

### ロール

SAP から提供される以下のビジネスロールテンプレートを使用して、ビジネスロールを登録し、それらを個別のテストユーザに割り当てます。

または、利用可能な場合は、SAP から提供される以下のスペースを使用することができます。スペーステンプレートを使用して、必要な事前定義済アプリを含むページのあるスペースを登録し、それをビジネスロールに割り当てます。その後、このビジネスロールを個別のユーザに割り当てます。

詳細については、SAP S/4HANA Cloud Public Editionの[Product Assistance](https://help.sap.com/docs/SAP_S4HANA_CLOUD/53e36b5493804bcdb3f6f14de8b487dd/ec310a8b669a45ca898dc4dd91d97de2.html)でテンプレートからのビジネスロールの作成方法を参照してください。

| 名称 (ロールテンプレート) | ID (ロールテンプレート) | 名称 (ラウンチパッド領域) | ID (ラウンチパッド領域) |
| --- | --- | --- | --- |
| 保全計画者 | SAP_BR_MAINTENANCE_PLANNER | 保全計画 | SAP_BR_MAINTENANCE_PLANNER |

## 手順

### 機能場所マスタデータの登録

目的

このテストステップでは、1 つの最上位の機能場所と 2 つの下位の機能場所で構成される機能場所構造を更新します。

手順

| テストステップ番号 | テストステップ名 | 指示 | 予想される結果 | コメント |
| --- | --- | --- | --- | --- |
| 1 | ログオンする | SAP Fiori ラウンチパッドに 保全計画者 としてログオンします。 |  |  |
| 2 | アプリを開く | 技術対象セクションで技術対象登録タイルを選択します。 |  |  |
| 3 | 機能場所を登録する | 技術対象登録画面で、技術対象タイプ: 機能場所を選択します。次の画面で、以下のエントリを更新します。技術対象タイプ: 機能場所構造区分: YBPM (ベストプラクティスの構成区分)技術対象: <識別子などを入力します> ZZ01技術対象カテゴリ: S (カスタマロケーション)続行を選択します。 |  |  |
| 4 | 一般データを更新する | 技術対象登録: ZZ01 画面の一般データセクションで、以下のエントリを更新します。テキスト: <建物 A など>オプションで、その他の一般データを更新してから、場所データセクションにナビゲートします。 |  |  |
| 5 | 場所データを更新する | 場所データセクションで、以下のエントリを更新します。保全プラント: <1710 などの US に関連するプラントを更新します>注記 同じ構造に属する技術対象にはすべて同じプラントが割り当てられている必要があります。あるいは、すべての技術対象でプラント情報を空白のままにしておくこともできます。オプションで、住所情報などのその他の詳細を更新します。 |  |  |
| 6 | 機能場所を保存する | オプションで、組織データセクションにある取引先情報などの追加情報を更新することもできます。保存を選択します。この後、ホーム画面に戻ります。 |  |  |
| 7 | 下位の機能場所を登録する | 機能場所構造を更新するには、上記ステップを実行して以下の機能場所を更新します。技術対象: ZZ01-001テキスト: 1 階技術対象: ZZ01-002テキスト: 2 階 |  |  |
| 8 | 設備ビューアで技術対象をレビューする | ホームページで、技術対象照会タイルを選択します。技術対象照会画面で、ZZ01 などの関連する 技術対象を更新してから、続行を選択します。機能対象ごとに機能場所構造および詳細をレビューするには、以下も可能: 設備ビューアでの技術対象照会を選択します。 |  |  |

### 設備マスタデータの登録

目的

このテストステップでは、機能場所に設置されている設備のレコードを更新します。

手順

| テストステップ番号 | テストステップ名 | 指示 | 予想される結果 | コメント |
| --- | --- | --- | --- | --- |
| 1 | ログオンする | SAP Fiori ラウンチパッドに 保全計画者 としてログオンします。 |  |  |
| 2 | アプリを開く | 技術対象登録を開きます。 |  |  |
| 3 | 設備を登録する | 技術対象登録画面で、技術対象タイプ: 設備を選択します。次の画面で、以下のエントリを更新します。技術対象タイプ: 設備技術対象: <空>有効開始: <本日の日付>技術対象カテゴリ: S (得意先設備)続行を選択します。 |  |  |
| 4 | 一般データを更新する | 技術対象登録: <設備 ID> 画面の一般データセクションで、以下のエントリを更新します。テキスト: <プリンタ A1 など>(オプション) 得意先保証: 保証開始/終了(オプション) 仕入先保証: 保証開始/終了注記 社内修理プロセス (スコープアイテム 3XK) では、日付 (保証期間) に基づく保証がサポートおよび統合されます。社内修理では、得意先保証および仕入先保証の保証タイプを使用することができます。設備マスタデータに保証開始日付と保証終了日付を入力する必要があります。設備の得意先/仕入先保証の終了日付を入力した場合は、保証終了日付が社内修理の登録日付よりも前であるかチェックされます。アイコンは、社内修理の登録日付が保証期間内であるかどうかを示します。オプションで、製造業者情報、モデル番号などのその他の一般データを更新してから、場所データセクションにナビゲートします。 |  |  |
| 5 | 品目およびシリアル番号を割り当てる | 追加機能 > シリアル番号データ表示を選択します。以下のエントリを入力し、Enterを選択します。品目: TG20 |  |  |
| 6 | 場所データを更新する | 場所データセクションで、以下のエントリを更新します。保全プラント: <1710 などの US に関連するプラントを更新します>注記 同じ構造に属する技術対象にはすべて同じプラントが割り当てられている必要があります。あるいは、すべての技術対象でプラント情報を空白のままにしておくこともできます。オプションで、住所情報やルーム情報などのその他の詳細を更新します。 |  |  |
| 7 | 設備を保存する | オプションで、組織データセクションにある取引先情報などの追加情報を更新することもできます。保存を選択します。 |  |  |
| 8 | 機能場所に設備を設置する | 技術対象変更: <設備 ID> 画面で、構造セクションにナビゲートします。構造変更: インストールを選択します。設置場所変更ダイアログボックスで、以下のエントリを更新します。上位技術対象: ZZ01-001ポジション: <空白のまま>設置日時: <システム提案を保持します>OK を選択します。保存を選択します。 |  |  |
