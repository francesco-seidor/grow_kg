## 目的

注意！这是未审核准确性的机器翻译文档。要发送有关翻译的反馈，您可以在 SAP Signavio Process Navigator 中针对您的国家/地区版本在范围项目页面上创建客户工单。

在本文档中，您可以找到有关如何创建包含价格的服务产品主数据记录的描述。该描述包括与主数据相关的数据段，以便在“常规”系统环境中工作。读取器主要学习哪些数据段和字段通常需要使用输入值填充。此文档不描述与范围无关的字段，尽管这些字段可能显示在 UI 上。

按此处描述创建的服务产品主记录，可用于服务订单 和服务确认处理。

| 服务产品标识 | 描述 | 用法 |
| --- | --- | --- |
| SRV_01 | 服务 | 表示服务本身，例如安装、维修、维护 |
| SRV_CONTRACT | 合同产品 | 表示合同中的服务本身 |
| SRV_CTR_RENEWAL | 服务合同续订产品 | 代表与 签订的合同中的服务合同产品 自动更新的预设值 |
| SRV_02 | 服务费用 | 反映可能因服务产生的费用，例如差旅成本、 燃料 |
| SRV_03 | 备件（未定义） | 反映服务所需的物料，并允许自由文本 描述只能采购此非库存物料 |
| SRV_04 | 备件（已定义） | 以最小/无物流将物料反映为非库存 集成只能采购此非库存物料 |
| SRV_05 | 库存服务备件 | 反映将从库存中提取的物料（从库存拣配） 场景） |
| SRV_06 | 含序列号参数文件的库存服务备件 | 反映具有已分配序列号参数文件的物料， 取自库存（从库存拣配场景） |
| SRV_BUNDLE_01 | 服务包 01 | 表示复杂服务，作为含子项目的包 |
| SRV_BUNDLE_02 | 服务包 02 | 表示包含子项目（服务项目）的包形式的复杂服务 和固定价格项目） |
| EXP_FSM_TRAVELEXP_FSM_MEALSEXP_FSM_OTHEREXP_FSM_MILEAGE | 服务费用 | 反映费用，例如，差旅成本或餐饮（在以下情况下） 与 SAP Field Service Management 集成。 |
