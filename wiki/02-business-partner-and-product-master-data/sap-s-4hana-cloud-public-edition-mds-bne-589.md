## 目的

ビジネスコンテキスト

サプライヤまたは仕入先は、商品およびサービスを組織に提供、販売するビジネスパートナです。たとえば、仕入先も商品を購入する場合、ビジネスパートナは仕入先であると同時に得意先でもあります。

仕入先マスタには、仕入先の名前、住所、振込先銀行情報、税の詳細、請求の希望などの仕入先に関する情報が保有されます。この仕入先情報は、購買発注、入庫、サプライヤ請求書などのトランザクションで使用および保存されます。

一部の仕入先情報は、特定の会社 (会社コードと呼ばれる) または組織内の購買ユニット (購買組織と呼ばれる) に固有です。

### データ登録の主要パラメータ

このセクションでは、マスタレコードの動作に影響し、サプライヤマスタデータレコードの登録に常に必要となる基本パラメータの一部について説明します。

#### ビジネスパートナグルーピングと番号範囲

ビジネスパートナグルーピングでは、ビジネスパートナ ID の番号範囲を決定します。割当または ID を後から変更することはできません。ビジネスパートナグルーピングが内部番号範囲に割り当てられている場合は、ビジネスパートナ ID をマニュアルで入力することはできません。この場合は、割当済の数値番号範囲から自動的に数値が選択されるため、この項目は空白のままにしておきます。

ビジネスパートナ (得意先、仕入先、取引先担当者、従業員など) に対しては、以下のビジネスパートナグルーピングと対応する番号範囲が定義されます。

| ビジネスパートナグルーピング | 範囲/ビジネスパートナ ID | コメント |
| --- | --- | --- |
| BP01 | 外部数値番号範囲 (低)1 から 999999 | たとえばこのグループを使用して、数値マスタデータレコードを移行します。 |
| BP02 | 内部数値番号範囲 (基本用途)1000000 から 9999999 | ビジネスパートナグループが入力されていない場合は、この番号範囲がデフォルトで使用されます。 |
| BP03 | 外部数値番号範囲 (高)10000000 から 999999999 | SAP サンプルマスタデータオブジェクトで使用するために予約済です。 |
| BPAB | 外部英数字番号範囲:A から ZZZZZZZZZZ | この範囲は文字で開始する必要があります。 |
| BPEE | 内部数値番号範囲:9980000000 から 9999999999 | ビジネスパートナ従業員で使用するために予約済です。 |

#### ビジネスパートナ ID

ビジネスパートナ ID

ビジネスパートナ ID の割当に関して以下のオプションが利用可能です。

- ID は外部採番のビジネスパートナグルーピングを使用して入力します。例

| ビジネスパートナグルーピング | ビジネスパートナ ID の入力可能値 |
| --- | --- |
| BP01 | 対応する番号範囲 1 から 999999 までの任意の番号 |
| BPAB | 最大 10 桁の英字で開始される英数字の組み合わせ (例、Z-TEST01) |

ビジネスパートナグルーピングを指定せずにビジネスパートナ ID を空白のまま残した場合は、ビジネスパートナグルーピング BP02 から次の空き番号が使用されます。このグルーピングは内部数値ビジネスパートナ ID の標準グルーピングとして定義されています。

ビジネスパートナデータ機能

ビジネスパートナデータ機能は、業務トランザクションでの各パートナの権限および責任を決定します。

購買管理のパートナ機能の例としては次のものがあります。仕入先、請求元、品目供給者など

#### 勘定グループ

勘定グループは、サプライヤマスタレコードの ERP データセグメント登録のための上位制御パラメータです。現在サプライヤマスタデータに対してサポートされている勘定グループは SUPL のみです。
