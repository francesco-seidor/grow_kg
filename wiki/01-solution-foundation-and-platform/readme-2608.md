## README

This README-file contains a short description and an overview of the downloaded ZIP file.

This ZIP file contains 2 folders:

1. packExcel

2. Senario specific folder (e.g. S4C or IBP)

------------------------------------------------------------------------------------------------------------------------------------

1.
In the packExcel folder there is an Excel sheet with all links and URL´s which are provided as an accelerator on the related Solution Scenario.
Its different sheets (Solution Scenario, Solutoin Process,...) represents the enity level on which the URL has been assigned to.

2.
The scenaro specific folder contains a "Library" folder with another folder directories.
This folders contain the physical assets e.g. Master Data Overview, Availability Dependencies or Test scripts which has been assigned and uploaded to the respective entity.
