## Purpose

This document provides a description for creating a freight agreement in your SAP S/4HANA Cloud Public Edition system. The description only includes relevant data segments such as Organizational Units and Master Data. Fields that are not relevant for the scope of the SAP Best Practices for SAP S/4HANA Cloud Public Edition configuration content are not described in this document.

Freight agreements (FAs) are the basis for calculating transportation charges. You use freight agreements to calculate billable transportation charges.

An agreement includes contractual data, such as the following:

- Purchasing Organisation
- Carrier
- Validity dates
- Calculation Sheet Items
- Rates

##### Create Locations from Shipping Points and Customers

This batch job is used to create locations for business partners and shipping points.

Locations used for the following scenarios are delivered by SAP:

- 6W1 – External Transportation Planning (Outbound and Inbound scenarios).
- 6W2 – Manual Transportation Planning (Outbound and Inbound scenarios)

For the Stock Transport Order scenario an additional plant and shipping point is needed, which you have to create following the setup instruction guide for scope item Stock Transfer with Delivery (BME). In this master data guide we use plant 1720 as an example.

This batch job is mandatory to be scheduled for the newly created shipping point, as the example freight agreement described in this guide uses shipping point location-specific rates. If you don’t use location-specific rates in your freight agreement, you don’t need to create locations using the batch job before. In that case, the locations (for business partners and shipping/receiving points) are created automatically by the system when you save a business document (that is sales order, purchase order) for a business partner with a shipping point.
