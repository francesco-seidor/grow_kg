## 目的

この文書では、SAP S/4HANA Cloud Public Editionシステムに運送契約を登録する方法について説明します。組織ユニットやマスタデータなど、関連するデータセグメントについてのみ説明します。SAP S/4HANA Cloud Public Edition 向け SAP Best Practices設定コンテンツの範囲に関連しない項目については、この文書では説明していません。

運送契約 (FA) は、輸送費計算の基準になります。運送契約を使用して、請求可能な輸送費を計算します。

契約には、以下のような契約データが含まれます。

- 購買組織
- 運送業者
- 有効日付
- 計算書明細
- レート

|  |
| --- |
| 注記 注記: 運送契約は、自動コンテンツ有効化を使用したデモデータとして提供されます。ただし、技術的な制約により自動登録できないレートもあります。在庫転送および拡張会社間シナリオをテストするには、自動コンテンツ有効化後にこれらのレートをマニュアルで登録する必要があります。このマニュアルステップは、該当するテーブルで説明されています。 |

##### 出荷ポイントおよび得意先からのロケーション登録

このバッチジョブは、ビジネスパートナと出荷ポイントのロケーションを登録するために使用します。

以下のシナリオで使用されるロケーションは、SAP によって提供されます。

- 6W1 -外部輸送計画 (送信および受信シナリオ)
- 6W2 -マニュアル輸送計画 (送信および受信シナリオ)

在庫転送オーダーシナリオでは、追加のプラントおよび出荷ポイントが必要です。これは、スコープアイテム出荷伝票を使用した在庫転送 (BME) の設定手順のガイドに従って登録する必要があります。このマスタデータガイドでは、例としてプラント1720を使用します。

このガイドで説明する運送契約の例では、出荷ポイントロケーション固有のレートが使用されるため、新規登録する出荷ポイントに対して、このバッチジョブをスケジュールする必要があります。運送契約でロケーション固有のレートを使用しない場合は、事前にバッチジョブを使用してロケーションを登録する必要はありません。この場合、出荷ポイントを使用してビジネスパートナの業務伝票 (受注、購買発注) を保存すると、(ビジネスパートナおよび出荷/入荷ポイントの) ロケーションが自動的に登録されます。
