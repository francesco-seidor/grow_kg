## Objetivo

Este documento fornece uma descrição para criar um acordo de frete em seu sistema SAP S/4HANA Cloud Public Edition. A descrição só inclui segmentos de dados relevantes, como unidades organizacionais e dados mestre. Os campos que não são relevantes para o escopo do conteúdo de configuração do SAP Best Practices para SAP S/4HANA Cloud Public Edition não estão descritos neste documento.

Os programas de remessas são a base do cálculo de custos de transporte. Você usa acordo de frete para calcular custos de transporte calculáveis.

Um programa inclui dados contratuais, como os seguintes:

- Organização de compras
- Transportadora
- Datas de validade
- Itens da folha de cálculo
- Tarifas

|  |
| --- |
| Nota Nota Fornecemos acordos de frete como dados de demonstração com ativação automática de conteúdo. No entanto, existem algumas tarifas que não podem ser criadas automaticamente, devido a restrições técnicas. Para testar a transferência de estoque e cenários interempresariais avançados, você precisa criar manualmente essas taxas após a ativação automática de conteúdo. Essas etapas manuais são explicadas nas tabelas afetadas. |

##### Criar unidades gerenciais a partir de locais de expedição e clientes

Esse job em lote é usado para criar unidades gerenciais para parceiros de negócios e locais de expedição.

As unidades gerenciais usadas para os seguintes cenários são fornecidas pela SAP:

- 6W1 - Planejamento de transporte externo (cenários de saída e de entrada).
- 6W2 - Planejamento de transporte manual (cenários de saída e de entrada)

Para o cenário de ordem de transferência de estoque, é necessário um centro e um local de expedição adicionais, que você deve criar seguindo o guia de instruções de configuração para o item de escopo Transferência de estoque com remessa (BME): Neste guia de dados mestre, usamos como exemplo o centro 1720.

É obrigatório programar este job em lote, já que o exemplo de acordo de frete descrito neste guia usa taxas específicas do local de expedição. Se você não utilizar taxas específicas da unidade gerencial no seu acordo de frete, você não precisa criar antes unidades gerenciais utilizando o job em lote. Nesse caso, as unidades gerenciais (para parceiros de negócios e pontos de expedição/recebimento) são criadas automaticamente pelo sistema quando você salva um documento comercial (por exemplo, ordem do cliente, pedido) para um parceiro de negócios com um local de expedição.
