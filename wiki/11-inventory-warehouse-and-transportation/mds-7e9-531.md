### 管理位置

目的

以下步骤显示如何创建位置。

过程

| 测试步骤编号 | 测试步骤名称 | 指令 | 预期结果 | 备注 |
| --- | --- | --- | --- | --- |
| 1 | 登录 | 登录到 SAP Fiori 快速启动板 作为 主数据专家 - 运输管理 。 | 随即显示 SAP Fiori 快速启动板。 |  |
| 2 | 访问应用 | 打开 管理位置 (F6225) 。 | 因此， 管理位置主数据 (F6225) 屏幕。 |  |
| 3 | 选择创建 | 选择 创建 。 | 因此， 创建 对话框。 |  |
| 4 | 输入详细信息 | 在 中 创建 对话框中，输入以下内容：位置： <您的位置>位置类型： <您的位置类型> |  |  |
| 5 | 选择继续 | 选择 继续 。 | 因此， 位置 屏幕。 |  |
| 6 | 输入基本信息 | 在 基本信息 标签上，输入以下内容：位置描述： <您的位置描述> |  |  |
| 7 | 输入地址数据 | 在 地址 标签上，输入以下内容：街道： <街道>邮政编码： <邮政编码>国家/地区： <国家/地区>门牌号： <门牌号>城市： <城市>地区： <地区>时区： <时区>搜索词 1： <搜索词> |  |  |
| 8 | 输入标识数据 | 在 标识 标签上，输入以下内容：UN/LOCODE： <UN/LOCODE>机场代码： <机场代码> |  |  |
| 9 | 选择计算地理坐标 | 选择 计算地理坐标 。 | 地理坐标自动确定并填充在 地理坐标 标签。 |  |
| 10 | 选择创建 | 选择 创建 。 | 出现以下系统消息：已成功创建位置 <您的位置> |  |
