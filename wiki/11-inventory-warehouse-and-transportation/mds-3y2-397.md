## 目的

この文書では、倉庫リソースのマスターデータの登録方法について学ぶことができます。倉庫モニタ (/SCWM/MON) アプリを使用して、倉庫リソースを更新することができます。この文書には、標準的なシステム環境で処理するマスタデータに関連するデータセグメントが含まれています。主に、入力値を入力する必要があるデータセグメントおよび項目について学習します。SAP Best Practices による SAP S/4HANA コンテンツ提供の範囲に関連しない項目については、画面に表示される場合でもこの文書では説明していません。このマスタデータは、すべての倉庫管理ビジネスプロセスに使用します。

この文書には、ソリューション有効化後にこのスコープアイテムをテストするための詳細な手順が示されています。これには、事前定義されたソリューション範囲が反映されています。各プロセスステップ、レポート、またはアイテムはそれぞれ個別のセクションで取り上げられ、システムインタラクション (テストステップ) がテーブルビューで示されます。プロセスの範囲内には含まれていなくてもテストに必要となるステップには、それに応じてマークが付いています。プロジェクト固有のステップを追加する必要があります。

### ロール

SAP から提供される以下のビジネスロールテンプレートを使用して、ビジネスロールを登録し、それらを個別のテストユーザに割り当てます。

または、利用可能な場合は、SAP から提供される以下のスペースを使用することができます。スペーステンプレートを使用して、必要な事前定義済アプリを含むページのあるスペースを登録し、それをビジネスロールに割り当てます。その後、このビジネスロールを個別のユーザに割り当てます。

詳細については、SAP S/4HANA Cloud Public Editionの[Product Assistance](https://help.sap.com/docs/SAP_S4HANA_CLOUD/53e36b5493804bcdb3f6f14de8b487dd/ec310a8b669a45ca898dc4dd91d97de2.html)でテンプレートからのビジネスロールの作成方法を参照してください。

## テスト手順

このセクションには、このマスタレコードに含まれる各セグメントまたはプロセスステップの手順が記載されています。

### 倉庫リソースの登録

目的

このセクションでは、倉庫モニタ(/SCWM/MON) アプリを使用して倉庫リソースを登録します。

手順

| テストステップ番号 | テストステップ名 | 指示 | 予想される結果 | コメント |
| --- | --- | --- | --- | --- |
| 1 | ログオン | SAP Fiori ラウンチパッドに倉庫担当者 (EWM) としてログオンします。 |  |  |
| 2 | アプリにアクセスする | 倉庫モニタ(/SCWM/MON)を開きます。 | 倉庫管理モニタダイアログボックスが表示されます。 |  |
| 3 | 倉庫番号を入力する | 倉庫管理モニタダイアログボックスが開いたら、以下のデータを入力します。倉庫番号: <各自の倉庫番号>実行を選択します。 |  |  |
| 4 | メニューを選択する | 左の画面領域にある階層で、リソース管理 > リソースの順に選択します。 |  |  |
| 5 | リソースを照会する | 表示されたダイアログボックスで、実行を選択します。 | 倉庫に対して登録されているすべてのリソースが表示されます。 |  |
| 6 | リソースを登録する | 追加メソッド > リソース登録の順に選択します。 |  |  |
| 7 | 値を入力する | 表示されたダイアログボックスで、以下のデータを入力します。リソース: <リソース ID>注記 リソース ID の上限は 18 文字です。実行を選択します。 | リソースが正常に登録されます。 |  |

### 倉庫リソースの削除

目的

このセクションでは、倉庫モニタ(/SCWM/MON) アプリを使用して倉庫リソースを削除します。

手順

| テストステップ番号 | テストステップ名 | 指示 | 予想される結果 | コメント |
| --- | --- | --- | --- | --- |
| 1 | ログオン | SAP Fiori ラウンチパッドに倉庫担当者 (EWM) としてログオンします。 |  |  |
| 2 | アプリにアクセスする | 倉庫モニタ(/SCWM/MON)を開きます。 | 倉庫管理モニタダイアログボックスが表示されます。 |  |
| 3 | 倉庫番号を入力する | 表示された倉庫管理モニタダイアログボックスで、以下のデータを入力します。倉庫番号: <各自の倉庫番号>実行を選択します。 |  |  |
| 4 | メニューを選択する | 左の画面領域にある階層で、リソース管理 > リソースの順に選択します。 |  |  |
| 5 | リソースを照会する | ダイアログボックスで、実行を選択します。 | 倉庫に対して登録されているすべてのリソースが表示されます。 |  |
| 6 | リソースを削除する | 削除対象のリソースを選択し、追加メソッド > リソース削除の順に選択します。 |  |  |
| 7 | 削除を確認する | リソース削除ダイアログボックスで、はいを選択します。注記 倉庫で使用中の特定のリソースは削除できません。つまり、ユーザがリソースにログオンしている場合、またはユーザがリソースをデフォルトリソースとして設定している場合です。 | リソースが正常に削除されました。 |  |
