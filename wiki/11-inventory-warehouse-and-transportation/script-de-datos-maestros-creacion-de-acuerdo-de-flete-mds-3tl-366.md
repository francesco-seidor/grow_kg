## Objetivo

ATENCIÓN Se trata de un documento traducido automáticamente que no se ha revisado para comprobar su exactitud. Para enviar comentarios sobre la traducción, puede crear un ticket de cliente en la página del elemento de alcance para su versión de país en SAP Signavio Process Navigator.

Este documento proporciona una descripción para crear un acuerdo de flete en su SAP S/4HANA Cloud Public Edición sistema. La descripción solo incluye segmentos de datos relevantes como Unidades organizativas y Datos maestros. Campos que no son relevantes para el alcance del SAP Best Practices for SAP S/4HANA Cloud Public Edition contenido de configuración no se describen en este documento.

Los acuerdos de flete (AF) son la base para calcular los costes de transporte. Los acuerdos de flete se utilizan para calcular los costes de transporte facturables.

Un acuerdo incluye datos contractuales, como los siguientes:

- Organización de compras
- Transportista
- Fechas de validez
- Posiciones de esquema de cálculo
- Tarifas

Sin embargo, hay algunas tarifas que no se pueden crear automáticamente debido a restricciones técnicas. Para probar el traslado de stock y los escenarios multisociedad avanzados, debe crear manualmente estas tasas después de la activación automática del contenido. Estos pasos manuales se explican en las tablas afectadas. |

##### Crear ubicaciones a partir de puntos de expedición y clientes

Este job de fondo se utiliza para crear ubicaciones para socios comerciales y puestos de expedición.

SAP proporciona las ubicaciones utilizadas para los siguientes escenarios:

- 6W1 – Planificación de transporte externa (Escenarios de salida y entrada).
- 6W2 – Planificación de transporte manual (Escenarios de salida y entrada)

Para el escenario Pedido de traslado se necesita un centro y un puesto de expedición adicionales, que debe crear siguiendo la guía de instrucciones de configuración para el elemento de alcance Traslado de stock con entrega (BME). En esta guía de datos maestros utilizamos el centro 1720 como ejemplo.

Este job de fondo es obligatorio para programarse para el puesto de expedición recién creado, ya que el acuerdo de flete de ejemplo descrito en esta guía utiliza tarifas específicas de la ubicación del puesto de expedición. Si no utiliza tarifas específicas de ubicación en su acuerdo de flete, no necesita crear ubicaciones utilizando antes el job de fondo. En ese caso, el sistema crea automáticamente las ubicaciones (para interlocutores comerciales y puntos de expedición/recepción) cuando guarda un documento comercial (es decir, un pedido de cliente, un pedido) para un interlocutor comercial con un puesto de expedición.
