## 目的

この文書では、SAP S/4HANA Cloud Public Editionシステムにロケーションマスタデータレコードを登録する方法について説明します。この説明には、"標準的" なシステム環境で処理するマスタデータに関連するデータセグメントが含まれています。主に、入力値を入力する必要があるデータセグメントおよび項目について学習します。SAP Best Practices によるSAP S/4HANA Cloud Public Editionコンテンツ提供の範囲に関連しない項目については、画面に表示される場合でもこの文書では説明していません。

## 前提条件

### システムアクセス

| システム | 詳細 |
| --- | --- |
| システム | SAP Fiori ラウンチパッドからアクセスすることができます。各自のロールに割り当てられている各種アプリにアクセスするための URL がシステム管理者から提供されます。 |

### ロール

SAP から提供される以下のビジネスロールテンプレートを使用して、ビジネスロールを登録し、それらを個別のテストユーザに割り当てます。

または、利用可能な場合は、SAP から提供される以下のスペースを使用することができます。スペーステンプレートを使用して、必要な事前定義済アプリを含むページのあるスペースを登録し、それをビジネスロールに割り当てます。その後、このビジネスロールを個別のユーザに割り当てます。

詳細については、SAP S/4HANA Cloud Public Editionの[Product Assistance](https://help.sap.com/docs/SAP_S4HANA_CLOUD/53e36b5493804bcdb3f6f14de8b487dd/ec310a8b669a45ca898dc4dd91d97de2.html)でテンプレートからのビジネスロールの作成方法を参照してください。

| 名称 (ロールテンプレート) | ID (ロールテンプレート) | 名称 (ラウンチパッド領域) | ID (ラウンチパッド領域) |
| --- | --- | --- | --- |
| マスタデータスペシャリスト - 輸送管理 | SAP_BR_TRANSP_MDSPEC | 輸送マスタデータ | SAP_BR_TRANSP_MDSPEC |

### データ登録の主要パラメータ

このセクションでは、マスタレコードの動作に影響を与え、<タイプ>マスタデータレコードの登録に常に必要となる基本パラメータの一部について説明します。

#### ロケーションタイプ

ロケーションタイプを割り当てるために、以下のオプションを使用することができます。

| 名称 | ID |
| --- | --- |
| 港湾 | 1100 |
| 空港 | 1110 |
| 鉄道駅 | 1120 |
| 鉄道接続駅 | 1190 |
| 積載ポイント: | 1200 |

#### UN/LOCODE の定義

貿易および輸送ロケーションの国連コード (UN/LOCODES) を定義することができます。

設定環境で、検索機能を使用して各アクティビティを見つけます。詳細については、[SAP S/4HANA Cloud Public Editionの設定環境](https://help.sap.com/docs/SAP_S4HANA_CLOUD/b249d650b15e4b3d9fc2077ee921abd0/0b3f87579f345c08e10000000a441470.html)を参照してください。

#### 空港コードの定義

空港コードを定義することができます。

設定環境で、検索機能を使用して各アクティビティを見つけます。詳細については、[SAP S/4HANA Cloud Public Editionの設定環境](https://help.sap.com/docs/SAP_S4HANA_CLOUD/61e246f4b34c4e1790d8b7651c0b40a8/0b3f87579f345c08e10000000a441470.html?state=DRAFT)を参照してください。

### ロケーション管理

目的

以下のステップでは、ロケーションを登録する方法を示します。

手順

| テストステップ番号 | テストステップ名 | 指示 | 予想される結果 | コメント |
| --- | --- | --- | --- | --- |
| 1 | ログオンする | SAP Fiori ラウンチパッドにマスタデータスペシャリスト - 輸送管理としてログオンします。 | SAP Fiori ラウンチパッドが表示されます。 |  |
| 2 | アプリにアクセスする | ロケーション管理(F6225)を開きます。 | ロケーションマスタ管理(F6225)画面が表示されます。 |  |
| 3 | 登録を選択する | 登録を選択します。 | 登録ダイアログボックスが表示されます。 |  |
| 4 | 詳細を入力する | 登録ダイアログボックスで、以下のエントリを入力します。ロケーション: <ロケーション>ロケーションタイプ: <ロケーションタイプ> |  |  |
| 5 | 続行を選択する | 続行を選択します。 | ロケーション画面が表示されます。 |  |
| 6 | 一般情報を入力する | 一般情報タブで、以下のエントリを入力します。ロケーションテキスト: <ロケーションテキスト> |  |  |
| 7 | 住所データを入力する | 住所タブで、以下のエントリを入力します。地名: <地名>郵便番号: <郵便番号>国/地域: <国/地域>番地: <番地>市区町村: <市区町村>地域: <地域>タイムゾーン: <タイムゾーン>検索語句 1: <検索語句> |  |  |
| 8 | ID データを入力する | IDタブで、以下のエントリを入力します。UN/LOCODE: <UN/LOCODE>空港コード: <空港コード> |  |  |
| 9 | 地理的座標計算を選択する | 地理的座標計算を選択します。 | 地理的座標が自動的に決定され、地理的座標タブに入力されます。 |  |
| 10 | 登録を選択する | 登録を選択します。 | 以下のシステムメッセージが表示されます。ロケーション <ロケーション> が登録されました |  |
