## 测试过程

本部分介绍作为此主记录一部分的每个段或流程步骤的过程。

### 创建仓库资源

目的

在本部分中，使用 仓库监控器 (/SCWM/MON) 应用。

过程

| 测试步骤编号 | 测试步骤名称 | 指令 | 预期结果 | 备注 |
| --- | --- | --- | --- | --- |
| 1 | 登录 | 登录到 SAP Fiori 快速启动板作为 仓库职员 (EWM)。 |  |  |
| 2 | 访问应用 | 打开 仓库监控器 (/SCWM/MON) 。 | 因此， 仓库管理监控器 对话框。 |  |
| 3 | 输入仓库编号 | 如果 仓库管理监控器 对话框中，输入以下数据：仓库编号 ： <您的仓库编号>选择 执行。 |  |  |
| 4 | 选择菜单 | 在屏幕左侧区域的层次结构中，选择 资源管理 > 资源 。 |  |  |
| 5 | 显示资源 | 在打开的对话框中，选择 执行 。 | 系统显示已为仓库创建的所有资源。 |  |
| 6 | 创建资源 | 选择 更多方法 > 创建资源 。 |  |  |
| 7 | 输入值 | 在打开的对话框中，输入以下数据：资源 ： <资源标识>备注 资源标识限制为 18 个字符。选择 执行。 | 资源已成功创建。 |  |

目的

在本部分中，使用 仓库监控器 (/SCWM/MON) 应用。

过程

| 测试步骤编号 | 测试步骤名称 | 指令 | 预期结果 | 备注 |
| --- | --- | --- | --- | --- |
| 1 | 登录 | 登录到 SAP Fiori 快速启动板作为 仓库职员 (EWM)。 |  |  |
